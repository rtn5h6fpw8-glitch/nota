# Нота

Бесплатная музыка в браузере, в стиле Apple Music.

- Артисты, альбомы и чарты по жанрам с Audius (независимые музыканты со всего мира)
- Альбомы, живые концерты и старые пластинки из Internet Archive
- Около 50 000 интернет-радиостанций (Radio Browser)
- Треки Jamendo (нужен свой бесплатный Client ID)
- Видео YouTube в официальном плеере
- Ваши собственные аудиофайлы, хранятся только в браузере

На iPhone: откройте сайт в Safari → «Поделиться» → «На экран „Домой“».
